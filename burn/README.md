# Burn

Omarchy theme from a Super Heavy night static fire. Ember void, flame gold, square corners, hairline borders. Sibling of [Space](../README.md).

Repo: [stevederico/omarchy-themes](https://github.com/stevederico/omarchy-themes).

## Palette

| Role | Hex |
|------|-----|
| Background | `#0C0500` |
| Card | `#1F0800` |
| Text | `#F3B34B` |
| Accent | `#EB9E2D` |
| Ember | `#CC730E` |
| Core | `#FFE894` |

## Install

```bash
mkdir -p ~/.config/omarchy/themes/burn
cp -a colors.toml hyprland.lua shell.toml icons.theme keyboard.rgb preview.png backgrounds \
  ~/.config/omarchy/themes/burn/
omarchy theme set burn
```
